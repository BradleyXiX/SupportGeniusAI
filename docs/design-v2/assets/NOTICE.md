# Asset provenance

Signal-prism mark, editable wordmark, particle SVG, SVG layout boards and reference code were authored for this SupportGenius AI design task. No assets from the supplied video are bundled. Project licensing remains the owner's decision.

Font subsets were downloaded from Google Fonts on 20 November 2026. Source families and SIL Open Font License notices:

- Space Grotesk — https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Plus Jakarta Sans — https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- JetBrains Mono — https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

See the `fonts/*-OFL.txt` files for the corresponding license notices. The distributed subsets cover Latin; additional language support requires matching subsets. The SVG wordmark uses editable font text and is not a fully outlined logotype.
