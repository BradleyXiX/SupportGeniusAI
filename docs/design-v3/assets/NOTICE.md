# Asset provenance (Crimson Signal v3)

The Crimson Signal design assets—including the signal-prism marks (`mark-crimson.svg`, `mark-white.svg`, `supportgenius-mark.svg`, `favicon.svg`), the static SVG poster fallbacks (`signal-core-poster.svg`, `closing-sphere-poster.svg`, `network-texture-poster.svg`), the console status avatar (`avatar-sphere.svg`), and the directional vector boards (`hero-direction.svg`, `closing-direction.svg`, `boards/direction-board.svg`)—were authored specifically for SupportGenius AI. No assets from the supplied reference video or external proprietary designs are bundled. Original project assets are proprietary under the root [LICENSE](../../../LICENSE) (`Copyright (c) 2026 Bradley Chiwo. All rights reserved.`).

## Font Subsets

Latin font subsets are located in `client/assets/fonts/`. Source families and SIL Open Font License 1.1 notices:

- Space Grotesk — https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Plus Jakarta Sans — https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- JetBrains Mono — https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

See `client/assets/fonts/*-OFL.txt` for the corresponding full license texts. The distributed WOFF2 subsets cover the Latin character set; additional language support requires downloading and bundling matching unicode-range subsets.
